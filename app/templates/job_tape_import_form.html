Import pre-existing tapes

Load these tapes into the library first. Each must already be LTFS-formatted with real content on it — this reads what's already there, it never formats or writes anything. A barcode Vader hasn't seen before is registered straight to archived status (never scratch), so nothing can pick it up for a future write or format job, no matter what order things happen in afterward.

Runs in the background, mounting each tape read-only and cycling through whichever drives are free: load → mount read-only → scan and classify content exactly like a write job would → hash every file → catalog → unmount → next tape. Can take a long time per tape since it reads the whole thing. Re-running against an already-imported tape skips anything already cataloged from it. One tape's failure doesn't stop the others; check the job's Result for per-tape unit counts and failures.
