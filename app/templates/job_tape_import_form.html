Import pre-existing tapes

Load these tapes into the library first. Each must already be LTFS-formatted with real content on it — this reads what's already there, it never formats or writes anything. A barcode Vader hasn't seen before is registered straight to archived status (never scratch), so nothing can pick it up for a future write or format job, no matter what order things happen in afterward.

Full import reads and SHA256-hashes every file, the same trust anchor used for anything else in the catalog — for a full LTO tape this takes as long as reading the whole tape (hours). Fast scan only reads the tape's index (seconds to minutes) so you can see what's on a tape and how full it is before committing to a full audit; content it catalogs is marked "scanned" rather than "verified" and a later full import will pick it back up and hash it properly. Re-running either mode against an already-verified tape skips what's already confirmed; a fast scan never skips ahead of a full import.

Runs in the background, mounting each tape read-only and cycling through whichever drives are free: load → mount read-only → scan and classify content exactly like a write job would → catalog (hashing every file in full-import mode) → unmount → next tape. One tape's failure doesn't stop the others; check the job's Result for per-tape unit counts and failures.
